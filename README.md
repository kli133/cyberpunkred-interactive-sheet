# Cyberpunk RED Interactive Sheet  
Локальный офлайн‑проект без сервера

## Возможности
- **Характеристики и навыки** по правилам *Cyberpunk RED*  
- **Режим создания персонажа** с ограничениями очков  
- **Жизненный путь** и элементы повседневной жизни  
- **Киберимпланты**  
- **Снаряжение и оружие**  
- **Броски кубиков** разных типов  
- **Преимущество и помеха**  
- **Формулы кубиков** в заметках  
- **Автосохранение в браузере**  
- **Импорт и экспорт персонажа в JSON**  
- **Автономная Windows‑версия (.exe)**  
- Полностью **офлайн**, без сервера

# Будущий план: автоматизация брони

Планируется полноценная система брони *Cyberpunk RED*:

### Основные элементы
- Раздельные значения **SP головы** и **SP тела**  
- **Текущий SP** с учётом абляции  
- **Калькулятор попадания**: голова или тело  
- Ввод **урона оружия** и автоматический расчёт итогового урона  
- Автоматическое уменьшение **HP персонажа**  
- Автоматическая **абляция брони** на −1 SP  
- Учёт **штрафов брони** к REF и DEX  
- Проверка **тяжёлого ранения**  
- Автоматическое добавление **критических травм**  
- **История попаданий и повреждений**  
- Поддержка **разных комплектов брони** и их характеристик
